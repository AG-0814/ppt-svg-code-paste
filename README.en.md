# PPT SVG Code Paste

[繁體中文](README.md) | English

A PowerPoint task pane add-in: paste SVG (XML) code and insert it into the current slide as a vector graphic, without saving it as an .svg file and importing it first.

Handy for dropping SVG code generated by AI or copied from an icon library straight into a deck, instead of asking the Claude for PowerPoint add-in to insert the shape for you.

![SVG Code Paste in PowerPoint: the "SVG 插入" (Insert SVG) button on the ribbon, the side pane with pasted code and a preview, and the inserted vector icon in the middle of the slide](docs/screenshot.png)

The screenshot shows the Traditional Chinese UI. If your Office display language is anything other than Chinese, the pane and ribbon button appear in English.

The icons in the screenshot (headphones, stairs) come from [Phosphor Icons](https://phosphoricons.com/) under the [MIT License](https://github.com/phosphor-icons/core/blob/main/LICENSE).

## Features

- Paste code into the side pane and get a live preview (checkerboard background shows transparent areas)
- Strips the ``` fences that come along when copying from a chat, adds `xmlns` if it is missing, and reports malformed XML
- Set the insert width (pt, 0 = original size), insert with Ctrl+Enter, optionally clear the box after inserting
- The result is an SVG graphic (vector). Right-click it in PowerPoint and choose "Convert to Shape" to recolor or take it apart
- Under the hood: Office.js `setSelectedDataAsync` with `Office.CoercionType.XmlSvg`
- The UI (pane and ribbon button) follows the Office display language: Chinese shows Traditional Chinese, every other language shows English

## Requirements

- PowerPoint for Windows (Microsoft 365 / 2019 or later, with SVG support)
- The pane is served from GitHub Pages, so an internet connection is required

## Installation (shared folder catalog)

This add-in is not on the Office Store. Install it through Microsoft's Shared Folder Catalog: you register a network share that holds the manifest in the Trust Center, and PowerPoint loads it from there on every start, so it survives restarts.

1. **Download the manifest**: Create a folder just for add-in manifests, e.g. `D:\OfficeAddins\ppt-svg-code-paste\`, and save this repo's [`manifest.xml`](manifest.xml) into it. Don't move this folder afterwards.

2. **Get a network share path**: The catalog only accepts network paths (`\\ComputerName\ShareName\...`), not local paths like `D:\...`. Pick one:
   - **Use the built-in administrative share (no setup)**: If your account is in the Administrators group, Windows shares every drive as `DriveLetter$` by default. For the example above the path is `\\localhost\D$\OfficeAddins\ppt-svg-code-paste`. Paste it into the File Explorer address bar first; if it opens, it works.
   - **Share the folder yourself**: Right-click the folder, choose "Properties > Sharing > Share", add yourself with Read permission. When done, the dialog shows the network path (e.g. `\\YourComputerName\ppt-svg-code-paste`).

3. **Register it in the Trust Center**: In PowerPoint go to "File > Options > Trust Center > Trust Center Settings > Trusted Add-in Catalogs", paste the network path from step 2 into "Catalog Url", click "Add catalog", tick "Show in Menu" for that row, then click OK.

4. **Restart PowerPoint and add it**: Fully close PowerPoint and reopen it. Go to "Home > Add-ins" (or "Insert > My Add-ins"), open the "SHARED FOLDER" tab, select SVG Code Paste and click "Add".

5. **Using it**: An "Insert SVG" button appears at the far right of the Home tab, available in every presentation. Click it to open the side pane.

### Uninstall

In the Trust Center's "Trusted Add-in Catalogs" list, select this path, click "Remove", and restart PowerPoint.

## Troubleshooting

| Symptom | Cause and fix |
| --- | --- |
| "This add-in has been disabled: add-ins inserted during development can only be used while debugging from Visual Studio" | The add-in was installed via developer sideloading (`npx office-addin-dev-settings sideload` or the `WEF\Developer` registry key). Developer sideloading only lasts for that session and is disabled after PowerPoint restarts. Run `npx office-addin-dev-settings unregister <manifest path>` (or delete the value named `4fa1aa32-29a9-4519-82dd-e7d9b2a5e3cc` under `HKEY_CURRENT_USER\Software\Microsoft\Office\16.0\WEF\Developer`), then install via the shared folder catalog above. |
| The add-in doesn't show up in the "SHARED FOLDER" tab | Check that "Show in Menu" is ticked for the path in the Trust Center, that PowerPoint was fully restarted, and that `manifest.xml` sits directly in that path. |
| The pane is blank or fails to load | Make sure you can reach <https://ag-0814.github.io/ppt-svg-code-paste/taskpane.html>. |
| The Insert button is grayed out and says "Not connected to PowerPoint" | The page was opened in a regular browser. Inserting only works inside the PowerPoint pane. |
| The UI language is wrong | Append `?lang=en` or `?lang=zh` to the page URL to force a language (handy for testing in a browser). |

For anything else, feel free to open an Issue or a Pull Request.
